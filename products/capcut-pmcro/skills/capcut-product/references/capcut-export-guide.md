# CapCut export guide

This reference is an instruction guide, not an execution claim. The current
default is `export-guide`: the user operates CapCut and reports the evidence.

## Choose the target

1. `browser-session`: use CapCut Web in an approved browser session. CapCut's
   online editor does not require a separate CapCut installation.
2. `desktop-session`: use CapCut Desktop on the user's computer. The user
   installs and opens the desktop application before the agent can use an
   approved computer-use surface.
3. If the target is not explicit, stay in `export-guide` mode.

## Browser export-guide

1. Open CapCut Web in the user's chosen browser.
2. Sign in or open the user's existing workspace; the agent must not collect
   credentials.
3. Open the project and confirm that the timeline is complete.
4. Select `Export`.
5. Choose the available resolution, quality, frame rate, and file format in the
   export settings.
6. Start the export and download the resulting file.
7. Record the output filename/path and any visible warning.

Web export availability can depend on the browser, device, source media,
network, account, and project. Do not promise 2K/4K or a watermark-free result.

## Desktop export-guide

1. The user installs CapCut Desktop from an official source and opens it.
2. Open the project and confirm that the timeline is complete.
3. Select `Export`.
4. Choose the required resolution, frame rate, codec/format, and bitrate when
   those controls are available.
5. Choose the output folder and start the export.
6. Record the output filename/path and any visible warning.

Desktop export settings and maximums depend on the project, source media,
hardware, operating system, and current CapCut version.

## PMCR-O completion evidence

An instruction packet is `instruction-ready`, not `execution-verified`.
Promote it only after the user or an approved execution adapter provides:

- selected target and platform;
- declared export settings;
- visible completion or error result;
- output filename/path or an explicit failure;
- independent checker result.
