# CapCut product prompts

## Prompt: scaffold a content product

```text
Create a bounded CapCut-oriented product scaffold for my declared identity. Read the parent marketplace and grant first. Generate only the manifest, agent surfaces, generic trail, prompts, validators, and documentation. Do not access accounts, credentials, uploads, publishing, or monetization.
```

## Prompt: plan one adapter

```text
Plan one possible CapCut adapter from validated resources. Keep it simulation-only until an authorized API, input/output contract, and independent checker exist. Return the smallest plan and one unexecuted next seed.
```
